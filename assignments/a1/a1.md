## Instructions

For this assignment, you'll be building and simulating a simple system based on a short specification:

The **processor** should:
- Execute instructions *in-order*,
- Have two cores,
- Use the RISC-V ISA,
- Have 4-instruction decode and execute input widths,
- Have an execute branch delay of 2 clock cycles.

The **cache hierarchy** should have:
- A 32 KiB private L1 instruction cache per core,
- A 24 KiB private L1 data cache per core,
- A 2 MiB private L2 cache per core.

The **memory system** should be a 16 GiB dual-channel DDR3-2133.

The **CPU clock speed** of the system should be 4GHz.

> All parameters not explicitly stated here can be left with "default" values.

You may be able to find some of these components "as-is" in the standard library; you will need to search through the existing components to determine what you should use. For the other component(s), you will need to parameterize them yourself as you've previously done in Unit II.

After building the components of the system, you will define it in a configuration script and simulate running the GAPBS BFS benchmark on it.
