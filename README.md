# gem5 Online Bootcamp Project

> **NOTE:** This project is *under construction!* All pages posted here are drafts. Feel free to make a pull request if you have any suggestions/edits/corrections!

This bootcamp is designed for self-paced, individual learning in unit/section order. It covers similar topics to days 1-3 of the [2024 gem5 bootcamp](https://gem5bootcamp.github.io/2024/) (introduction to simulation and gem5, using gem5, and developing gem5 models). Students should read through the lessons folder and complete the corresponding exercises in the workspace folder.
