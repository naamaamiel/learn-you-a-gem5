# New working directory alert!

For this section, be sure to write your new SimObject under `gem5/src/bootcamp` directory! Create the `bootcamp` directory under `gem5/src` and copy the `hello-sim-object` directory into the `bootcamp` directory to get started.

> All SimObject files (the files found in the `hello-sim-object` directory) should be in `gem5/src/bootcamp/hello-sim-object`.

Keep your configuration script (`hello_sim_object_config.py`) in the `workspace` folder.
